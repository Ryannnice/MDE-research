# 复现进度总览（2026-07-27）

> 一句话结论：支撑感知线的 `DPT/MiDaS Base + LayeredDepth + SeeGroup` 已完成，且两个预注册 gap 都成立；物理薄壳线的 `TablewareNet + T²SQNet` 已完成 100-scene 的 **GT-mask oracle**；`DFNet/TransCG` 与 `ReMake/TransCG` 的官方全量测试仍被 TransCG 数据下载配额阻塞。尚未开始训练 DepthHypothesisPack Head。

本文只汇总**本地实际完成的工作**。所有结果都标明协议，避免把 base fallback、跨数据集诊断、GT-mask oracle、smoke test 和官方原生 benchmark 混在一起。

### 绝不能误写成以下结论

- DPT/MiDaS Base 不是 Depth4ToM 微调模型；不能写成“Depth4ToM-FT 已复现”。
- SeeGroup 在 Booster 的 raw-metric 行不是其原生任务成绩；它只衡量不经标定直接跨协议使用时的错位。
- T²SQNet 当前结果使用官方 GT masks；不能写成 RGB 端到端 T²SQNet 成绩。
- T²SQNet 的 TablewareNet shell GT 是由官方参数模型生成的物理薄壳 oracle，不是实测透明物体内壁深度真值。
- DFNet / ReMake 只有 smoke 与运行准备，尚没有 TransCG official full-test 数值。
- 尚没有 planner 成功率、机器人成功率，也尚未训练新的 Head。

## 4. G0：TablewareNet、ShellBench、T²SQNet

### 4.1 数据与 shell oracle

- TablewareNet processed test：100/100 scene 有效、每 scene 4 个对象、共 400 对象；发布版本为 7-view 精简版，运行器采用等价的 `0..6` view fallback。
- shell GT：只统计含官方 `superparaboloid` hollow component 的 object-centric view，避免把不同物体的遮挡错误标成 cavity。
- 结果：259 个 hollow GT object、1,813 个 object-view ray-event map、0 skipped scene。
- 物理边界：官方 mesh 使用 `wall_parameter_t=0.01`。这支持薄壳表示诊断，但不替代真实玻璃的实测壁厚数据。

### 4.2 T²SQNet：全量 GT-mask oracle

这是当前 G0 最完整的可运行 baseline。它保留 released DETR3D、dummy batch、voxel carving、类别 voxel head 和 primitive reconstruction，只绕过 LangSAM 的 RGB→mask 阶段。

| 项目 | 数值 |
| --- | ---: |
| 输入 / 运行分母 | official GT masks；100 / 100 scene |
| GT hollow objects | 259 |
| predicted objects | 386 |
| 同类 + 0.10 m 中心门限匹配 | 244 |
| object precision / recall | 63.21% / 94.21% |
| 未匹配 GT / prediction | 15 / 142 |
| ray 数 | 139,238,400 |
| interface precision / recall / F1 | 81.50% / 76.94% / **79.15%** |
| matched interface MAE / RMSE | 1.839 / 2.285 mm |
| transition precision / recall / F1 | 75.81% / 71.44% / **73.56%** |
| topology-valid rate | 89.36%（仅在 fully-labelled topology rays 上） |

解读：给定正确 mask 后，T²SQNet 的 shape 路径已能对大量 object 恢复有序界面；但多余预测较多（142 个 unmatched prediction），还有 15 个 hollow GT object 漏匹配，而且仅 2.022% 的全部 rays 被预测为完整 topology 标签。因此它是有价值的 multi-layer / shape baseline，但不是“薄壳问题已经解决”的证据。

## 8. 状态标签说明

- **完成**：指定分母、checkpoint、协议和输出均已在本地真实运行。
- **GT-mask oracle**：模型的后续识别 / 几何模块真实运行，但输入 mask 来自 GT；不是端到端 RGB 结果。
- **跨协议 diagnostic**：故意把一个方法接入非原生协议以测量桥接问题；不能替代原生 leaderboard。
- **smoke**：验证环境、checkpoint 或单条路径，只证明可启动，不提供 benchmark 数值。
- **阻塞**：已经具备 runner 和权重，但缺少外部可用数据/权重；不是“未做”。
