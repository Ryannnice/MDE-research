# TransCG / DFNet Repro

Minimal command:

```bash
conda run -n transcg python 透明物体/复现/tools/transcg/run_dfnet_minimal.py \
  --out-dir 透明物体/runs/transcg/minimal_synthetic
```

The script loads:

- upstream code: `透明物体/external/transcg/official/`
- checkpoint: `透明物体/weights/transcg/checkpoint.tar`
- outputs: `透明物体/runs/transcg/`

See `透明物体/复现/TransCG_DFNet.md` for the full record and real TransCG data commands.
