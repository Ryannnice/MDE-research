# 透明物体研究目录

更新：2026-07-19

## 当前主线

当前统一主线是：

> **Shell-Aware Multi-Layer Transparent Grasping**
> 面向多层透明薄壳几何的机器人抓取。

核心不是宣称“透明物体抓取无人研究”，而是验证：在空心透明物体上，是否需要显式恢复外壁、内壁、rim、开口、局部壁厚和腔体自由空间，才能避免单 completed depth、粗粒度 shape 或 occupancy 带来的抓取错误。

## 当前版本答案

- **目前的 idea 版本**：`统一 Idea v2`。
- **目前的实验设计**：已有完整的 staged evidence plan，但还不是“已有完整实验结果”；所有主结果均待跑。
- **当前 gate**：`G0_shell_failure_and_gt_feasibility`。
- **G0 要回答**：GT 是否可信；ReMake、T²SQNet、Trans2Occ 等强近邻是否存在可重复的薄壳失败；这些失败是否会影响固定抓取规划。
- **G0 前不做**：不直接开发完整新模型，不宣称任务空白，不承诺机器人成功率提升。

## 维护规则

1. 新的主线判断直接更新统一 Idea，不再维护并行的编号发散稿。
2. 新实验只进入统一实验设计和 `ccfa.yaml`。
3. 原文报告、复现结果和推测分开写；未运行的数字保持 `TBD`。
4. 任何“首次 / 空白 / SOTA”表述都要先通过最新文献核验。
5. 已被 canonical 文档完整吸收的草稿直接删除；仍承载证据、复现记录或独立研究问题的文档保留。
